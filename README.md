# Titanic Dataset - Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA)
on the Titanic dataset using Python.

## Tools & Libraries
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Gender-wise Passenger Count
- Survival Count
- Age Distribution
- Survival Rate by Gender
- Survival Rate by Passenger Class
- Survival Rate by Embarked Port
- Missing Values Analysis
- Data Cleaning

## Key Findings
- Total Passengers: 891
- Survived: 342
- Not Survived: 549
- Female passengers had a higher survival rate.
- First class passengers had a higher survival rate.

## Conclusion
EDA helps understand passenger survival patterns
and important insights from the Titanic dataset.
